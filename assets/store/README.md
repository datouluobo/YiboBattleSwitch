# Store Assets

This folder contains editable source files for Microsoft Store listing materials.

Included:

- `ms-store-hero-2400x1600.svg`
- `ms-store-shot-01-account-switch.svg`
- `ms-store-shot-02-library-and-backup.svg`
- `ms-store-shot-03-recovery-and-diagnostics.svg`

Recommended workflow:

1. Open the SVG source in Figma, Illustrator, Inkscape, or a browser-based SVG editor.
2. Replace draft captions if the store positioning changes.
3. Export final PNG files in the exact dimensions required by Partner Center at submission time.
4. If you later capture real in-app screenshots, keep these SVG files as promotional alternates rather than deleting them.
