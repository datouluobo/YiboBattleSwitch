# YiboBattleSwitch 隐私政策

最后更新：`2026-07-05`

## 1. 总述

`YiboBattleSwitch` 是一个本地运行的 Windows 桌面工具。当前版本默认不提供在线账号系统、云同步、遥测统计或远程上传功能。

本政策说明当前版本在本地可能处理哪些数据，以及这些数据如何使用。

## 2. 我们可能处理的数据

为了提供账号切换、备份和恢复功能，软件可能在你的本地设备上处理以下信息：

- 你保存到本地账号库中的 `BattleTag`
- 你手动填写或导入的邮箱、手机号、备注
- 与本地切换相关的账号快照、备份数据和诊断快照
- 你设置的安装目录、启动设置、窗口大小等本地配置
- 与本地 Battle.net 状态相关的部分配置文件、缓存文件和注册表摘要
- 本地日志信息

## 3. 数据存储位置

当前版本的数据默认保存在你的本地设备中，例如应用数据目录、账号库目录、备份目录和日志目录。

这些数据不会由本软件自动上传到开发者服务器，因为当前版本没有内置遥测或远程同步功能。

## 4. 数据用途

这些本地数据仅用于以下目的：

- 保存当前登录状态
- 从本地账号库切换账号
- 导入和导出账号库
- 备份与恢复本地状态
- 展示当前状态、日志和诊断结果
- 保存你的本地应用设置

## 4.1 本地登录状态操作确认

在首次执行保存、切换、导入或导出账号库等高风险操作前，软件会提示其可能处理 Battle.net 本地配置、登录状态和相关缓存，并要求你确认已了解第三方兼容性与账号风险。

## 4.2 本地备份和导出风险

账号库、诊断快照或导出文件可能包含与本地登录状态有关的数据。请不要将这些文件发送给他人或上传至不受信任的位置；在跨设备迁移时，应仅在你自己控制的设备与存储空间中使用。自动备份使用 Windows DPAPI 与当前 Windows 用户绑定，不能作为跨设备迁移文件。手动导出文件要求设置至少 12 个字符的密码，并使用 Argon2id 派生密钥和 AES-256-GCM 加密；忘记密码后无法恢复。

## 5. 不会自动做的事

当前版本默认不会：

- 创建在线账号
- 把你的账号库自动上传到开发者服务器
- 把 BattleTag、邮箱、手机号或诊断快照自动发送到第三方
- 在后台接入广告网络、统计 SDK 或行为跟踪服务

## 6. 外部链接

软件内可能提供外部链接，例如：

- 项目主页
- 最终用户许可协议
- 隐私政策页面

当你主动点击这些链接时，系统会在默认浏览器中打开目标网页。此时，目标站点可能按其自身规则收集访问数据，这部分行为不受本软件控制。

## 7. 用户控制权

你可以通过以下方式控制本地数据：

- 删除本地账号
- 导出账号库后自行保管
- 清空日志
- 卸载软件并手动删除其本地数据目录

在删除或恢复前，请先确认是否已经备份所需数据。

## 8. 未成年人

本软件不是面向儿童专门设计的产品。若你所在地区对未成年人使用软件有额外限制，请在监护人指导下使用。

## 9. 政策变更

如果未来版本新增在线功能、遥测、崩溃上报、云同步或客服回传机制，本政策应同步更新。
