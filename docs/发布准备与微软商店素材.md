## 当前打包命令

- `npm run dist:win`
  生成普通安装包 `exe`
- `npm run dist:msix`
  生成未签名 `msix`

说明：

- `msix` 流程内部会短暂使用 `appx` 作为中间格式，但最终只输出 `msix`
- 当前脚本使用仓库内的占位 `identity/publisher`，等你提供正式的 Store 软件 ID 后再替换
- 上传到 Microsoft Store 后由平台侧完成正式签名，因此当前流程不绑定本地发布证书

## 商店名称与定位

建议显示名称：

- 中文：`YiboBattleSwitch`
- 英文：`YiboBattleSwitch`

一句话定位：

- 中文：`为需要频繁切换 Battle.net 账号的玩家提供更稳定、更清楚的本地切换体验。`
- 英文：`A local desktop tool for safer and clearer Battle.net account switching on Windows.`

目标用户：

- 拥有多个 Battle.net 账号，需要在同一台电脑上频繁切换的玩家
- 希望减少手工清理、重复登录和误操作成本的用户

## 商店长描述

中文长描述：

`YiboBattleSwitch 是一个面向 Windows 的本地桌面工具，帮助需要频繁切换多个 Battle.net 账号的玩家，更清楚地管理当前状态、保存常用账号，并在异常时快速回退。`

`应用会把你当前的 Battle.net 登录状态保存到自己的本地账号库中。之后你可以从账号列表中选择目标账号，执行切换、导出、导入、恢复备份或重新启动 Battle.net。整个流程尽量使用玩家能理解的界面语言，而不是要求你自己手动处理本地配置与恢复步骤。`

`YiboBattleSwitch 当前提供以下能力：`

- `保存当前登录状态到本地账号库`
- `从本地账号库切换到目标账号`
- `导出与导入账号库`
- `恢复最近一次推荐备份`
- `启动 Battle.net，并管理基础启动设置`
- `查看当前状态、最近日志和诊断操作`

`这不是一个云端账号平台，也不会替代 Battle.net 本身的认证体系。它的目标是把本地切换、回退和诊断过程做得更清楚、更稳定。YiboBattleSwitch 是独立第三方工具，不隶属于 Blizzard 或 Battle.net。`

英文长描述：

`YiboBattleSwitch is a Windows desktop utility for players who switch between multiple Battle.net accounts on the same PC. It focuses on making the local switching workflow clearer, more recoverable, and easier to understand.`

`The app can save the active Battle.net login state into its own local account library. From there, you can switch to a saved account, export or import the library, restore a recent backup, relaunch Battle.net, and inspect the current environment when something looks wrong.`

`Current capabilities include:`

- `saving the active login state into a local account library`
- `switching to a selected saved account`
- `exporting and importing the local library`
- `restoring the latest recommended backup`
- `launching Battle.net and managing startup-related settings`
- `reviewing logs, current state, and diagnostic actions`

`YiboBattleSwitch is not a cloud account manager and does not replace Battle.net authentication. Its purpose is to reduce repetitive manual work around local switching, backup, and recovery. It is an independent third-party tool and is not affiliated with Blizzard or Battle.net.`

## 上架前检查清单

1. 在发布候选构建上实际截图，替换当前示意型母版。
2. 在 Partner Center 中确认最终图片规格、数量限制和语言字段。
3. 准备隐私政策链接、支持链接和发布者信息。
4. 拿到正式 Store 软件 ID 后，把 `msix` 脚本里的占位身份参数换成 Partner Center 对应值。
5. 重新核对商店描述是否避免使用任何可能引发误解的第三方品牌表述。
6. 用发布构建完成一次完整回归：保存、切换、导入、导出、恢复、启动 Battle.net、托盘菜单刷新。
